1. Présentation du projet Saytu Mbeund

Saytu Mbeund est un système national d'alerte aux inondations en temps réel créé pour protéger les populations du Sénégal. Le projet permet à :

  • Les citoyens de faire des signalements lors d'une inondation
  • Les habitants de recevoir une alerte immédiate (téléphone, email, SMS)
  • Les autorités locales de prendre des décisions rapides
  • Les chercheurs d'étudier où et quand les inondations arrivent

Le système est actuellement opérationnel avec une application mobile que les gens peuvent utiliser maintenant.

2. Pourquoi nous avons besoin des cartes du PGIIS

Le PGIIS a travaillé pendant des années pour créer les cartes des zones inondables au Sénégal. Ces cartes sont essentielles.

Si nous avons ces cartes, Saytu Mbeund peut :

  • ✅ Informer les habitants des zones à risque d'inondation toute l'année
  • ✅ Aider les autorités à valider si un signalement se situe dans une zone inondable
  • ✅ Alerter les populations avant la saison des pluies si leur habitation est en zone à risque
  • ✅ Croiser les signalements d'inondation avec les zones inondables officielles
  • ✅ Aider les chercheurs à identifier les patterns d'inondation (zones récurrentes, saisonnalité, facteurs)

4. Comment nous envoyer les cartes

Format de livraison :

  • Les cartes que vous avez (format n'importe peu)
  • En fichier ZIP ou dossier compressé
  • Avec une description simple (quoi c'est, quand, où ça couvre)

Composition du dossier :

Dossier PGIIS_Cartes_Saytu_Mbeund/

├─ Zones inondables (tous les fichiers du PGIIS pour ces zones)
├─ Rivières et fleuves (tous les fichiers PGIIS)
├─ Lacs et retenues (tous les fichiers PGIIS)
├─ Régions (tous les fichiers PGIIS)
├─ Départements/Districts (tous les fichiers PGIIS)
├─ Communes (tous les fichiers PGIIS)
└─ INFORMATIONS.txt (voir ci-dessous)

Fichier d'informations à inclure :

Un simple fichier texte nommé INFORMATIONS.txt avec :

  • Qui a fait les cartes (PGIIS, quelle équipe)
  • Quand (année de création/dernière mise à jour)
  • Chaque carte : à quoi elle sert, ce qu'elle montre
  • Est-ce qu'on peut les partager librement ou pas

📎 Ce qu'on va faire avec vos cartes

Utilisation sur la carte interactive

Quand quelqu'un ouvre l'application Saytu Mbeund, il verra la carte du Sénégal avec :

  • Les zones en rouge = Inondent souvent (très à risque)
  • Les zones en orange = Inondent parfois (risque modéré)
  • Les zones en jaune = Inondent rarement (risque bas)
  • Les rivières et lacs = Pour voir les ressources d'eau

Utilisation pour les signalements

Quand quelqu'un signale une inondation, le système :

  • Vérifie si le signalement est dans une zone PGIIS
  • Aide à vérifier que c'est vraiment une inondation
  • Alerte les habitants et autorités de cette zone

Utilisation pour la recherche

Les chercheurs pourront analyser :

  • Où inondations réelles vs cartes PGIIS
  • Évolution des zones à risque
  • Périodes d'inondations (saison, fréquence)

À propos de Saytu Mbeund

Saytu Mbeund (qui signifie "sauve une vie" en wolof) est une application créée par des chercheurs et ingénieurs sénégalais pour protéger les populations contre les inondations.

Les habitants peuvent :

  • 📱 Signaler une inondation quand ils la voient
  • 🔔 Recevoir une alerte immédiate par téléphone
  • 📧 Recevoir des informations par email
  • 📲 Recevoir des SMS si besoin
  • 🗺️ Voir les zones à risque sur une carte
